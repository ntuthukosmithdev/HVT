# HVT, High Voltage Technology SA (Pty) Ltd

| Folder | Contents |
| --- | --- |
| [`site/`](site/) | The corporate website (Next.js 16, TypeScript, Tailwind CSS). See [`site/README.md`](site/README.md) to run and deploy it, and [`site/HANDOVER.md`](site/HANDOVER.md) for content-verification notes. |
